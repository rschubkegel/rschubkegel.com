[Twenty-first Century Townball](https://21ctownball.com/) is a bat-and-ball game based on the version of base ball played in Massachusetts before the Civil War. I play and love the game, so I volunteered to design and build its website.

<FlexBasedImageContainer childrenProps={[
	{ src: homeImage, alt: "Home page" },
	{ src: rulesImage, alt: "Rules page" },
	{ src: historyImage, alt: "History page" },
]} />

The site is built with [Astro](https://astro.build/). Alongside the rules, history, and media pages, I created a Git-powered content management system that converts CSV files into stats pages, so game records can be updated by committing a spreadsheet rather than editing code.

<Image src={statsImage} alt="Player stats page for Chuck Jones" />

The project is [open source](https://github.com/21ctownball/townball-website) and uses GitHub issues and projects to plan contributions.
